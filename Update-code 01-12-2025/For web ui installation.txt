2. Enable and start services

Enable and start ZFS services:

sudo systemctl status zfs.target
see it active and enabled.
If not, enable it:
sudo systemctl enable zfs.target
sudo systemctl start zfs.target

sudo systemctl status zfs-import-cache.service
sudo systemctl status zfs-import-scan.service
see it active and enabled.
If not, enable it:
sudo systemctl enable zfs-import-cache.service
sudo systemctl enable zfs-import-scan.service
sudo systemctl start zfs-import-scan.service


Enable and start iSCSI target service:

sudo systemctl status target
see it active and enabled.
If not, enable it:
sudo systemctl enable target
sudo systemctl start target

Enable and start Samba service:

sudo systemctl status smbd
see it active and enabled.
If not, enable it:
sudo systemctl enable smbd
sudo systemctl start smbd

4. To create the service 

⚙️ Step 1: Create the Backend Systemd Service


sudo nano /etc/systemd/system/backend.service

[Unit]
Description=ZFS Backend
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/Documents/Web-1/backend
ExecStart=/bin/bash -c 'source venv/bin/activate && python main.py'
Restart=always
RestartSec=5
StandardOutput=append:/var/log/backend.log
StandardError=append:/var/log/backend_error.log

[Install]
WantedBy=multi-user.target
----------------------------------
running as the root

[Unit]
Description=ZFS Backend (Venv)
After=network.target

[Service]
WorkingDirectory=/home/ubuntu/Web-Nas/backend
ExecStart=/home/ubuntu/Web-Nas/backend/venv/bin/python3 main.py
Restart=always
StandardOutput=append:/var/log/backend.log
StandardError=append:/var/log/backend_error.log

[Install]
WantedBy=multi-user.target
----------------------------------

⚙️ Step 2: Create the Frontend Systemd Service

sudo nano /etc/systemd/system/frontend.service

[Unit]
Description=ZFS iSCSI Manager Frontend
After=network.target

[Service]
User=ubuntu
Environment=HOME=/home/ubuntu
Environment=NVM_DIR=/home/ubuntu/.nvm
WorkingDirectory=/home/ubuntu/Documents/Web-1/frontend
ExecStart=/bin/bash -c 'source $NVM_DIR/nvm.sh && nvm use 20 && npm run dev'
Restart=always
RestartSec=5
StandardOutput=append:/var/log/frontend.log
StandardError=append:/var/log/frontend_error.log

[Install]
WantedBy=multi-user.target



⚙️ Step 3: Enable and Start Both

Run these commands to activate the services:

sudo systemctl daemon-reload
sudo systemctl enable backend.service
sudo systemctl enable frontend.service
sudo systemctl start backend.service
sudo systemctl start frontend.service

🧭 Step 4: Check if They’re Running

Check backend:

sudo systemctl status backend.service

Check frontend:

sudo systemctl status frontend.service

🪵 Logs (for debugging)

Backend logs:

sudo tail -f /var/log/backend.log
sudo tail -f /var/log/backend_error.log

Frontend logs:

sudo tail -f /var/log/frontend.log
sudo tail -f /var/log/frontend_error.log


🔁 (Optional) Restart Both After Editing Code

Whenever you change code:

sudo systemctl restart backend.service
sudo systemctl restart frontend.service


✅ Result:
Now, every time your Ubuntu system boots:

The backend will auto-start as root at http://localhost:8000

The frontend will auto-start as ubuntu at http://localhost:3000

5. Configure sudo Access
Allow the application user to run specific commands without password
The application requires sudo access for ZFS and iSCSI operations. Add the following to  (use `sudo visudo`):


sudo visudo

Paste the following lines in the end f file

ubuntu ALL=(ALL) NOPASSWD: /usr/bin/targetcli, /usr/sbin/targetcli
ubuntu ALL=(ALL) NOPASSWD: /usr/sbin/iscsiadm
